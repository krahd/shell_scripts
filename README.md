Some simple shell scripts and configuration files for macOS and macOS apps.
Most likely useless to everyone but me.

- **init-commit-create-push-github** converts the param directory into a git repo and uploads it to GitHub (it creates a new repo in GH as well)
- **img_sorter** a kludge
- **mailmate_config** my chosen hidden options for MailMate
- **tom_mailmate_key_bindings.dict** my key bindings for MailMate
- **update_mailmate_key_bindings** copies the dict file to where it goes, making a backup of what was already there
- **.zshrc** a backup copy
